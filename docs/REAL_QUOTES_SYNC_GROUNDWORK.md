# FEG Stage PRO v3.10.2 — Real Quotes Sync groundwork

Этот слой готовит проекты/сметы к первому реальному серверному сохранению, но не выполняет боевую запись автоматически.

## Что добавлено

- `QuoteServerSyncQueue` — локальная очередь staged-sync для проектов.
- Sync-status проекта:
  - `local_only` — проект только локальный или ещё не готов к серверной записи;
  - `ready_to_sync` — dry-run проходит, проект можно ставить в очередь;
  - `staged` — проект поставлен в очередь будущей синхронизации;
  - `synced` — проект помечен как синхронизированный;
  - `sync_error` — зафиксирована ошибка синхронизации.
- В Backend / Sync добавлен блок `Real Quotes Sync groundwork`.
- Проекты в истории показывают sync-badge.
- Staged queue хранится локально в `fegV4QuoteServerSyncQueue`.

## Безопасность

- Реальная запись в Supabase не выполняется.
- Stage-кнопка только собирает payload и dry-run report.
- Remote write остаётся закрытым, пока явно не включены backend config и будущий write executor.
- Очередь можно скачать и проверить до отправки.

## Назначение

Этот слой нужен, чтобы спокойно перейти от local/PWA режима к серверной базе:

1. менеджер сохраняет проект локально;
2. система проверяет dry-run payload;
3. проект получает статус `ready_to_sync`;
4. проект ставится в staged queue;
5. будущий backend-write слой сможет обработать очередь.
