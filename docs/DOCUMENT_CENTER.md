# Document Center v3.9.1

`DocumentCenter` собирает проектные документы из `QuoteDocumentBuilder` и показывает их в одном рабочем центре.

## Что входит

- КП клиенту.
- Техлист.
- Общий и секционные складские листы.
- План резерва.
- План движения склада.
- Warehouse workflow.
- План субаренды.
- Calendar draft / ICS.
- Quote JSON, Export Pack JSON, Backend Sync Payload JSON.

## Безопасность слоя

Модуль не меняет расчёты, остатки склада и данные проекта. Он только собирает документы, показывает предпросмотр, копирует и скачивает текстовые/JSON-представления.
