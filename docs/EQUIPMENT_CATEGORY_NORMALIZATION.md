# FEG Stage PRO v3.11.0 — Equipment category normalization

Безопасный слой нормализации категорий базы оборудования перед реальной синхронизацией `equipment_items`.

## Что добавлено

- стабильная карта категорий `CATEGORY_TREE` + `CATEGORY_CODE_PREFIXES` остается базовой структурой;
- добавлен `CATEGORY_ALIASES` для импорта и ручного ввода: `звук`, `свет`, `кабели`, `услуги`, `бэклайн`, `фермы`, `LED` и другие варианты приводятся к внутренним `category id`;
- `normalizeItem()` теперь сохраняет исходную категорию в `meta.originalCategory`, если она пришла как алиас;
- подкатегории приводятся к написанию из дерева категорий, если найдено точное совпадение по нормализованному токену;
- нестандартные подкатегории не удаляются и не перезаписываются, а попадают в диагностику;
- добавлен `buildCategoryReport()` для проверки:
  - распределения позиций по категориям;
  - соответствия кода префиксу категории;
  - нестандартных подкатегорий;
  - нормализованных алиасов;
  - дублей кодов.

## UI

В базе оборудования добавлен блок «Нормализация категорий» и кнопка `Категории JSON`.

Отчет нужен перед импортом реальной базы и перед включением backend sync. Он ничего не записывает на сервер и не меняет складские остатки.

## Data Quality Center

Аудит оборудования теперь подсвечивает:

- код не соответствует категории;
- нестандартная подкатегория;
- категория была нормализована из алиаса.

## Ограничения слоя

- расчеты сцены, ферм и LED не менялись;
- LED-крепеж, печеньки и болты не трогались;
- автоматическое движение склада не включалось;
- запись в Supabase не включалась;
- старый v3-интерфейс не менялся.
