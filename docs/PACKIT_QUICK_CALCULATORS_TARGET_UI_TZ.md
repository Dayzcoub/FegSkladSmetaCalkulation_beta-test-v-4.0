# PACK.IT / FEG Stage PRO — ТЗ quick calculators target UI

Дата фиксации: 2026-05-26
Статус: целевой UI-контракт для точечной правки раздела **Быстрый расчёт** после checkpoint `PACK.IT unified dark UI baseline`.

## 1. Границы задачи

Правка относится только к экрану **Быстрый расчёт** и его четырём рабочим режимам:

1. Сцена.
2. Фермы.
3. LED экран.
4. 3D фермы MDM.

Тёмная тема считается базовой. Light theme не трогать.

Запрещено без отдельной прямой задачи менять:

- расчёты;
- BOM-формулы;
- склад/резервы/дефицит;
- PDF-логику;
- quick drafts/localStorage;
- legacy/v3;
- backend writes;
- структуру quote wizard.

Все изменения должны быть UI-layer: HTML shell, визуальные runtime-enhancements, CSS modules, shared tokens/classes. Inline styles и локальные костыли не добавлять.

## 2. Общий целевой каркас quick workspace

Все четыре быстрых калькулятора должны иметь один каркас:

- верхний заголовок внутри страницы: `Быстрые расчёты › <режим>`;
- подзаголовок с кратким назначением текущего режима;
- справа/ниже компактный action-bar:
  - `Сохранить`;
  - `Загрузить`;
  - `PDF`;
  - `Очистить`;
  - `Auto-fit`;
- блок `БЫСТРЫЕ КАЛЬКУЛЯТОРЫ`;
- 4 крупные карточки-переключателя:
  - `Сцена` — `Схема · Техлист · Склад · Вес`;
  - `Фермы` — `Схема · Техлист · Склад · Вес`;
  - `LED экран` — `Кабинеты · Кабели · Мощность · Вес`;
  - `3D фермы MDM` — `GLB · Просмотр · Масштаб · Sandbox`;
- блок `QUICK WORKSPACE`;
- основная рабочая зона конструктора;
- нижняя зона с табами и информационными карточками.

Активная карточка режима подсвечивается синим border/accent. Нельзя использовать зелёный как основной active-state для quick tabs.

## 7. Responsive contract

Desktop/tablet:

- верхние quick tabs — 4 колонки;
- action-bar справа от заголовка, при нехватке ширины переносится вниз;
- нижняя зона может быть 2 колонки.

Mobile `<=767px`:

- quick tabs — 2 колонки;
- action-bar — 2 колонки;
- нижняя зона — одна колонка;
- 3D MDM scaffold — одна колонка;
- без промежуточного breakpoint churn, не возвращать старые 860/900/1024/1179 хаки.

## 8. Реализация этого прохода

Этот проход должен:

- добавить документированный UI-контракт в `docs/`;
- добавить scoped CSS-layer для quick target layout;
- добавить лёгкий runtime-enhancer, который приводит текущий quick shell к целевому виду без переписывания расчётов;
- подключить CSS после текущих quick CSS слоёв;
- подключить runtime после `V4AppShell.js`;
- оставить существующие Stage/Truss/LED конструкторы и их расчётные callback-и без изменений.
