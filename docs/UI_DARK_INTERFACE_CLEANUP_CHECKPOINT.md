## Единый UI-contract для всех страниц

### Shell

- Левый nav rail фиксированный.
- Topbar единый на всех страницах.
- `packit-page` — единственный внешний контентный контейнер страницы.
- Desktop scroll — нативный браузерный/контентный scroll, без wheel-bridge/manual scroll hacks.

### Page layout

Каждая страница должна состоять из одного из паттернов:

1. `packit-content-wide` — одна широкая колонка.
2. `packit-content-layout` — основная зона + правый sticky-panel.
3. `v4-quote-layout` — мастер/пошаговый workflow.
4. `packit-quick-shell` — быстрые технические конструкторы.

Нельзя создавать уникальные page-wrapper-ы без необходимости.

### Cards

- Основная карточка: `packit-card` или `v4-card`.
- Вторичная карточка: surface/card helper из общего layout CSS.
- Заголовок карточки: `packit-card-head` / `v4-card-head`.
- Никаких отдельных border/radius/padding для одного экрана, если это можно выразить общим классом.

### Buttons

- Primary action: `btn-primary`.
- Secondary action: `btn-secondary`.
- Compact buttons — только для маленьких toolbars, не для футеров/форм.
- В мастерах: footer action group всегда справа, back всегда слева.

### Forms

- Label сверху, control снизу.
- Одинаковая высота контролов на desktop: 34px, если модуль не требует другого.
- По возможности 2–3 колонки, но без сжатия читаемости.
- Не использовать вложенные `<form>` внутри `<form>`.

### Tables/lists

- Таблицы и списки должны жить внутри карточки.
- Header / row / footer должны иметь одинаковый ритм отступов.
- Empty state должен быть отдельной карточкой/строкой, а не случайным текстом.

## Запрещённые практики до завершения cleanup

- Новые inline styles для геометрии (`style="padding..."`, `style="display..."`, `style="margin..."`).
- Новые `!important`, кроме удаления старого конфликта при невозможности иначе.
- Точечные CSS-костыли под один элемент без переноса в общий contract.
- Новые CSS-файлы, подключённые напрямую в `index.html`.
- Изменения расчётов, BOM, склада, резервов, backend writes и бизнес-логики без отдельной задачи.

- Проверить все разделы на общий page wrapper.

### Pass 3 — Workflows

Страницы: `quick`, `quote`.

- Проверить быстрые калькуляторы stage/truss/LED/MDM.
- Проверить мастер сметы 1–10.
- Убрать оставшиеся временные post-render фиксы там, где источник уже можно поправить безопасно.

### Pass 4 — System pages

Страницы: `sync`, `admin`, `quality`, `reports`, `settings`, `communication`, `command`.

- Привести консоли и служебные панели к единому card/table pattern.
- Убрать inline toolbar/card styling.
- Проверить пустые состояния и состояния доступа.

### Pass 5 — Final dark theme review

- Desktop widths.
- Mobile <=767px.
- Переходы между разделами.
- Модалки.
- Таблицы.
- Футеры мастеров.
- Сервисный кеш.
