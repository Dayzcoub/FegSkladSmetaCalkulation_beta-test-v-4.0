# Command Center v3.9.7

Command Center — глобальный поиск и командная панель v4-preview.

Индексирует:
- разделы dashboard по роли пользователя;
- проекты из локальной истории;
- клиентов из CRM;
- оборудование из единой базы;
- документы активного проекта.

Команды не меняют расчёты и складские остатки. Они только открывают нужный раздел или проект.

## Проверка

1. Открыть v4-preview.
2. Войти через Demo Auth.
3. Открыть «Поиск / Команды».
4. Проверить запросы: `склад`, `КП`, `DLive`, `LED`, имя клиента или код оборудования.
