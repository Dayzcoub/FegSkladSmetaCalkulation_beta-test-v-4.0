# v3.10.3 — Performance feedback

Цель слоя: убрать ощущение зависания при тяжёлых локальных операциях в проектах/истории смет и центре документов.

Что добавлено:

- `BusyIndicator` — общий UI-индикатор выполнения.
- Индикация для сохранения проекта, открытия проекта, смены статуса, экспорта, удаления и копирования проекта.
- Индикация при первичной сборке Document Center и при выгрузке больших пакетов документов.
- Кэш чтения/нормализации `QuoteProjectStorage`, чтобы фильтры, статусы и обновления не перечитывали и не нормализовали всю историю чаще необходимого.

Что не менялось:

- расчёты сцены/ферм/LED;
- печеньки/болты LED;
- складские остатки;
- backend-запись;
- старый v3-интерфейс.
