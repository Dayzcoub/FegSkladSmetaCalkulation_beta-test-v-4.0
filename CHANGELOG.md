# FEG Stage PRO Changelog

## v3.17.50 — Quick PDF summary dark text

- Усилен контраст текста в верхних сводных карточках quick PDF для сцены, ферм и LED.

## v3.17.49 — Quick PDF readable scheme fallback

- Исправлен контраст quick PDF: таблицы и коды получают inline light styles, чтобы глобальная тёмная тема не перебивала цвет текста/шапки.
- Для quick Stage и quick LED добавлен data-driven SVG fallback схемы из текущего конфига, если `html2canvas` не может снять DOM-поле конструктора.
- Quick Truss продолжает использовать снимок текущего поля, но получает тот же high-contrast PDF layer.
- Сметчик, склад, дефицит, совместимые замены, BOM-формулы и backend-записи не менялись.
- Добавлена документация `docs/V4_QUICK_PDF_READABLE_SCHEME_FALLBACK_3_17_49.md`.

## v3.17.48 — Quick PDF constructor scheme snapshot

- Быстрый PDF Stage / Truss / LED теперь использует снимок текущего поля конструктора, а не общий проектный visualizer / `VisualExport`.

- Текст PDF переведён на светлую тему: чёрный / тёмно-серый текст, светлый hero-блок, читаемые карточки, таблицы и footer.

## v3.17.45 — Truss balanced template split

- Добавлен общий shared-алгоритм `balancedStraightSegmentTypes` для разбиения прямых пролётов шаблонов ферменного конструктора.
- Quick и Quote конструкторы ферм теперь при автопостроении порталов, рам и табуреток стараются избегать коротких модулей, если есть более ровное точное деление.
- Пример: пролёт 4.5 м строится как 2.5 м + 2.0 м, а не как 3.0 м + 1.5 м.
- Если пролёт точно равен длине одной фермы 3 / 2.5 / 2 / 1.5 / 1 / 0.5 м, ставится один соответствующий модуль.
- Default truss section builder также переведён на тот же shared splitter, чтобы поведение quick/quote оставалось единым.
- Добавлена документация `docs/V4_TRUSS_BALANCED_TEMPLATE_SPLIT_3_17_45.md`.

## v3.17.38 — truss compatibility groups and alternative lengths

- Добавлен слой совместимости ферм: truss-позиции получают `meta.trussCompatibilityGroup`, `trussFamily`, `trussInterface`, `trussSpecType`, `trussPartKey` и для прямых ферм `trussLengthM`.
- Сметный ферменный конструктор в `catalogMode: quote` теперь может использовать совместимые складские позиции разных производителей, если совпадает группа совместимости, тип детали и длина.
- Добавлен BOM-план альтернативной сборки прямых ферм: при нехватке прямой длины конструктор пробует собрать её из доступных совместимых длин, например `3 м → 2 м + 1 м`.

- Quick-режим остаётся изолированным через `quick_ideal_catalog`; едиными остаются шаблоны, визуал, геометрия, нагрузки и формулы.

## v3.17.37 — truss catalog stock binding

## v3.15.62 — V4 LED hanging fasteners width-row formula
